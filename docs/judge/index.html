Where does the AI suggestion stop?

A declared source, a converted text layer and an AI-ranked proposal can disagree. BioSURE shows the difference and binds its review-only decision to a receipt. The declared source itself is not authenticated, so these public-input examples select no corrected output.

This is an interactive static replay of frozen Python-engine results using public or fictional samples—not a live document checker, benchmark win, human time study or upload service. The default public case uses one complete article-page-1 title, excludes the abstract, and abstains.
