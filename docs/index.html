BioSURE

AI4S · Tool & Platform · Offline research prototype

Inspect a converted paragraph sequence against a declared reference. Apply one supported structural edit, or leave the document for manual review.

Bounded correction

One internal missing paragraph or one extra exact duplicate. Normalized output and difference positions remain inspectable.

Batch & upstream review

Inspect both paragraph sequences for each batch record. Validate an actual pasted upstream proposal: unsupported wording and unrelated changes are withheld, not silently replaced.

Learned correspondence

A trained model ranks likely paragraph matches and flags lexical number, unit and negation differences for review only. It tied a strong lexical baseline on constructed held-out queries; it cannot approve a repair.

PDF text-layer review

A local import returns unverified page chunks and capped, page-specific review hints, not faithful paragraphs. Hints are balanced across pages so earlier line-wraps cannot hide all later-page warnings. In a JHU article excerpt, three embedded images had text the importer could not read; manual page comparison remains required.

Two-source OoC PDF audit

Four fixed title/abstract units comprise two controls and two genuine text-layer errors after a v0.3.3 importer bug was corrected. BioSURE restored 0/2 errors automatically; correct-reference copy was exact on all 4/4 units and a normal diff flagged 2/2 errors. This is not independent validation or measured time saving.

Three-source cross-publisher PDF audit

Across Nature, MDPI and Frontiers PDFs, five of six predeclared title/abstract units were scorable. Three differed from continuous reference text; BioSURE abstained on all five and restored none automatically. Correct-reference copy was exact on all five. The source-derived adjudication is not independent validation or evidence of an advantage over copying. Read the protocol.

Eight-source locked audit

A later metadata-locked OoC/MPS audit scored 16 first-page title/abstract units across four development and four held-out sources. Eleven differed from continuous JATS text, including reflow/typography. BioSURE corrected 0/11 automatically and abstained on 16/16; correct-reference copy was exact on 16/16 by construction. The video above predates this audit. Read the protocol and limits.

Explicit trust boundary

A false reference can produce a false output. Receipts bind content; they do not authenticate the reference or prove biological truth.

Run the real workbench locally

Download/extract the release, install Python 3.12 if needed, and run from its source root:

python -m pip install -e .
python scripts/verify_reproduction.py .
python -m biosure.web_demo

Open the printed loopback URL. Runtime uses Python, BSD-licensed pypdf, and MIT-licensed pdfplumber and fontTools, with no model download, GPU, paid API or external inference. This page hosts only the demonstration, not an online document-upload service. The JHU pilot and all three OoC/MPS PDF audits find no automatic BioSURE repair advantage over copying a correct reference; inspect the same-input results and Go/No-Go before relying on the tool.
