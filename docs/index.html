BioSURE

AI4S · Tool & Platform · Offline research prototype

Inspect a converted paragraph sequence against a declared reference. Public inputs remain review-only: no corrected text is selected or applied.

Try your own text or PDF → A no-login browser trial runs the public Python engine locally in your browser. PDF text-layer extraction is unverified and editable; no document bytes are uploaded, no correction is automatically applied, and source authenticity is not checked.

Inspect fixed-case Judge Mode → A sample-only static replay of reproducible engine decisions and receipts. It accepts no uploads; the separate live trial above accepts visitor text and PDF text layers.

Open the comparison-study instrument → Nine frozen tasks rotate across plain side-by-side, ordinary diff and BioSURE views. It keeps answers in browser memory for local JSON export. There are no participants or measured user benefits yet; fictional controls are not natural-source validation.

Bounded review candidate

One internal missing paragraph or one extra exact duplicate. Difference positions and proposed text remain inspectable; public input selects no corrected output.

Batch & upstream review

Inspect both paragraph sequences for each batch record. Validate an actual pasted upstream proposal: unsupported wording and unrelated changes are withheld, not silently replaced.

Learned correspondence

A trained model ranks likely paragraph matches and flags lexical number, unit and negation differences for review only. It tied a strong lexical baseline on constructed held-out queries; it cannot approve a repair.

PDF text-layer review

A local import returns unverified page chunks and capped, page-specific review hints, not faithful paragraphs. Hints are balanced across pages so earlier line-wraps cannot hide all later-page warnings. In a JHU article excerpt, three embedded images had text the importer could not read; manual page comparison remains required.

Two-source OoC PDF audit

Four fixed title/abstract units comprise two controls and two genuine text-layer errors after a v0.3.3 importer bug was corrected. BioSURE restored 0/2 errors automatically; correct-reference copy was exact on all 4/4 units and a normal diff flagged 2/2 errors. This is not independent validation or measured time saving.

Three-source cross-publisher PDF audit

Across Nature, MDPI and Frontiers PDFs, five of six predeclared title/abstract units were scorable. Three differed from continuous reference text; BioSURE abstained on all five and restored none automatically. Correct-reference copy was exact on all five. The source-derived adjudication is not independent validation or evidence of an advantage over copying. Read the protocol.

Eight-source locked audit

A metadata-locked OoC/MPS audit scored 16 first-page title/abstract units across four development and four held-out sources. Eleven differed from continuous JATS text, including reflow/typography. BioSURE corrected 0/11 automatically and abstained on 16/16; correct-reference copy was exact on 16/16 by construction. The video above shows one public title in fixed Judge Mode, not all 16 audit units. Read the protocol and limits.

Learned proposal versus strong baselines

On those same eight documents, the fitted model ranked 14/16 title/abstract units correctly and proposed copied-reference text for 12/16 units; it abstained on two sources. On four held-out sources, model ranking was 7/8 versus 8/8 for difflib and token Dice. Correct-reference copy was 16/16 exact by construction; reversed-reference failure control was 0/16. The gate automatically repaired none. This is a negative comparison, not an algorithmic win. Inspect every source result.

Two new sources, frozen follow-up

A separate metadata-locked follow-up tested two further CC BY 4.0 OoC articles after the v0.3.14 video was recorded, without tuning the model or gate. Four title/abstract units were scorable; one PDF-text/JATS difference remained. BioSURE abstained on 4/4 and repaired none. The learned model and both lexical rankers tied at 4/4 on this tiny follow-up; this does not erase the earlier model loss or prove user benefit. Read the lock and limits.

Explicit trust boundary

A false reference can produce a false review candidate. Public inputs remain review-only. Receipts bind content; they do not authenticate the reference or prove biological truth.

Run the real workbench locally

Download/extract the release, install Python 3.12 if needed, and run from its source root:

python -m pip install -e .
python scripts/verify_reproduction.py .
python -m biosure.web_demo

Open the printed loopback URL. Runtime uses Python, BSD-licensed pypdf, and MIT-licensed pdfplumber and fontTools, with no model download, GPU, paid API or external inference. This page streams the v0.3.22 recording from the same site; its live browser trial accepts user text or PDF entirely in browser memory. The JHU pilot and all three OoC/MPS PDF audits find no automatic BioSURE repair advantage over copying a correct reference; the learned source-held-out ranker also loses to simple lexical comparators. Inspect the same-input results and Go/No-Go before relying on the tool.
