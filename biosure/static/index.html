Reference → bounded edit → receipt

Paste a reference you have permission to use and its transformed paragraph sequence. Separate paragraphs with a blank line. Supports one internal missing paragraph or one extra exact duplicate, not translation or biological validation. PDF text-layer import is a review aid, not a faithful document conversion.

Local in-memory processing; no external inference or server-side input storage. Do not enter patient data. Downloads contain your supplied text. A false reference can produce a false result.

PDF import does not read text baked into figures. Check the original pages, columns, formulas, tables and every unverified page chunk before acknowledging a reference.

    AI / upstream proposal: validate pasted output

    Paste a proposed repaired sequence from your upstream tool or AI assistant. BioSURE checks that actual proposal against the reference and converted inputs above; it never silently replaces the proposal. This local app does not call an AI model or authenticate the producer.

    A supported one-edit match may be applied. Invented wording, unrelated edits and unsupported original differences require manual review. No learned-model accuracy or source truth is inferred.

    Advanced: inspect your own candidate JSON

    Same v2 gate; no text reconstruction from hashes. Maximum 32 candidates, 128 blocks per graph, 256 evidence entries and 1 MiB HTTP body.
