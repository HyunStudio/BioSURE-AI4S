# English demonstration narration

1. BioSURE is an offline document integrity workbench for life-science research. This is a Tool and Platform prototype, not a trained biological prediction model.
2. These fictional reference and converted paragraphs have one internal methods paragraph missing. The supplied reference is an assumption, not authenticated truth.
3. The same candidate-specific gate approves one bounded insertion. The interface shows its position, normalized text and a replayable JSON receipt.
4. An extra exact duplicate is also supported. The original file is never overwritten.
5. A substituted paragraph stays for manual review. Seeing a difference does not authorize a semantic change.
6. The graph inspector rejects unsupported candidate content and abstains when supported candidates disagree. Gold is not a decision input.
7. The article probe has nine constructed cases from three CC BY 4.0 OoC articles. Reference and gold share a source; this is not independent experimental validation.
8. The stress suite forges both candidate and evidence. All twelve forged-reference cases are wrongly applied. Reconstruction ties the earlier probes and produces more correct stress outputs. No superiority or real-world error rate is claimed.
9. Offline replay checks three sets. Six fictional batch inputs produce two corrections, one unchanged record and three manual reviews. These are functional checks, not time-saving measurements.
10. BioSURE offers inspectable differences, bounded triage and reproducible decisions. It cannot verify units, doses, source truth or biological meaning. Practical usefulness and AI-workflow integration remain to be independently evaluated.
